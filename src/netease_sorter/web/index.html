使用教程 从登录网易云到生成歌单，8 步 · 点开 / 收起
  1. 登录网易云网页版

    新开一个标签页打开 music.163.com，点右上角「登录」，扫码或手机号都行。 这个标签页先别关，第 7 步还要用它执行脚本。

  2. 复制歌单链接

    进入想整理的歌单页面，点右上角「分享」→「复制链接」，会得到形如 https://music.163.com/playlist?id=123456789 的地址。

    只支持公开歌单。私密歌单和「我喜欢的音乐」需要登录态，得用命令行的 fetch --liked。

  3. 粘贴到上方输入框并加载

    把链接贴进「粘贴歌单链接或 id」的框里，点「加载歌单」。进度条会依次显示 「获取详情 → 拉取歌词 300/1200 → 分类中」。几千首大概 1~3 分钟，期间页面可以正常滚动。

  4. 核对分类

    「语种」和「曲风」都可以多选：同一种里选多个是「或」，语种和曲风之间是「且」。 再用搜索框找具体某首；勾上「只看待复核」可以专门检查置信度低的歌，判错的直接不选它就行。

  5. 选出要的歌

    点行首勾选框单选，或者点「全选筛选结果」把当前筛选到的全选上。 顶部会实时显示「已选 N 首」；选中的行是浅红底色。

  6. 生成歌单

    点「生成写入脚本」，弹窗里可以改歌单名（默认按你当前的筛选命名，比如「我的歌单 · 日语 · 二次元」）。

    如果命令行里登录过（netease-sorter login --from-edge），页面顶部会显示「已登录」， 直接点「直接写入账号」就行——进度会显示在弹窗里，完成后给出歌单链接，可以直接跳到第 8 步。

    没有登录态时才需要往下走第 7 步：复制弹窗里的脚本，到网易云页面执行。 弹窗里的脚本会自己查重：同名歌单已存在时会问你要不要继续，不会悄悄建重复的。

  7. （可选）回到网易云页面执行脚本

    切到第 1 步那个已登录的网易云标签页，按 F12 打开开发者工具，切到 Console（控制台）。

    第一次粘贴代码时浏览器会拦，提示 Don't paste code…，按提示手动输入 allow pasting 再回车。

    然后把脚本粘到最下面的输入框，回车。

  8. 查看结果

    如果是「直接写入账号」，弹窗会显示「完成：《歌单名》现有 N 首」并给出「打开歌单」链接。

    如果是脚本方式，控制台会依次打印「已创建《…》→ 第 1 批 100 首 OK → … → 完成，共 N 首」， 每批之间隔 1 秒左右，几千首要几分钟，别关标签页。

    两种方式建出来的歌单默认都是私密，去网易云「我的歌单」能看到，想公开在客户端里改一下。

卡住了？
  • 进度条变红显示「解析不出歌单 id」→ 链接不完整，确认里面带 ?id= 和数字。
  • 加载出来是空的 → 歌单是私密的，换成公开歌单。
  • 控制台显示「创建失败」→ 把那段红字连同歌单链接发我，多半是接口参数变了。
  • 写了重复的歌 → 删掉新歌单，或在弹窗里把歌单名改成新的。
  • 不想用浏览器执行 → 命令行 netease-sorter create，见项目 README。

公开歌单不需要登录。加载会替换当前数据（约 1~2 分钟，几千首时）。
